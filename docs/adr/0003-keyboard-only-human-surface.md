# 0003 — Direct human editing

Human interaction is direct keyboard and mouse Document editing plus model/effort selection when Configuration is visible. Clicking an outlined control focuses it and opens a clickable option list upward; keyboard movement and selection remain available after focus. There is no palette, prompt workflow, preview, manual save, or TUI binding for showing or focusing Configuration. Surface mode is controlled through MCP, while exit remains a two-press `ctrl+c`; agent mutations never move the human cursor, selection, or viewport, and explicit MCP focus changes restore each Document's saved view state.
