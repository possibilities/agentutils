# 0002 — Bare fxnk Surface

The Surface renders the focused Document, an optional outlined Configuration picker, either one alone, or a quiet standby field. The picker's two controls occupy three bottom rows and an open option list participates in layout above them instead of covering the Document. It borrows visual roles solely from the fxnk style guide and has no persistent header, footer, filename, path, line-number gutter, help text, send affordance, or surrounding controls.
